Section 01

Channels & Cadence

Four active channels, each with a distinct role and rhythm. Quality over quantity — but consistency is non-negotiable.

Blog HomeTruths

2–3
posts per week

Long-form SEO content, guides, data pieces. The organic engine. Every post ends with an AI Advisor CTA.

X @HomeTruthUK

3–4
posts per day

Fast-moving, opinionated, data-led. Threads, hot takes on property news, stat drops, poll questions. Build the voice.

LinkedIn Monty + Jason

3–5
posts per week each

Thought leadership, founder stories, market analysis. Monty = public voice, industry. Jason = product, data, AI. Carousel format for data.

Email Newsletter

1
issue per week

"The Home Truth" — weekly digest. One insight, one stat, one blog link, one AI Advisor prompt. Short, sharp, valuable.

Section 02

AI Drafting Workflow

Every piece starts as an AI draft, then gets a human pass. Speed without sacrificing voice.

1

Brief

Pick title from the plan. Set pillar, audience, channel, CTA, key data points.

2

AI Draft

Claude generates first draft using HomeTruth voice guidelines and CLAUDE.md context.

3

Human Edit

Jason or Monty review for voice, accuracy, opinion. Add personal angle or anecdote.

4

Publish + Repurpose

Publish to primary channel. Spin into 2–3 secondary formats (thread, carousel, email excerpt).

Repurposing Matrix

Primary FormatRepurpose Into
Blog post (1,500+ words)X thread (5-8 tweets) + LinkedIn carousel + newsletter excerpt + 2-3 standalone X posts
LinkedIn founder postX post + blog expansion (if it resonates) + newsletter feature
Data report / researchBlog summary + X thread + LinkedIn carousel + PR pitch + email feature
X thread (if it goes viral)Blog post (expanded) + LinkedIn repost with context + newsletter deep-dive
PR op-ed (Monty)LinkedIn post + X thread + blog republish + email feature
